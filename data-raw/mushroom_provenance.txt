Species name mapping (old -> corrected):
arvenis -> fissuratus
benesi -> benesii
califorinus -> californicus
cupreo-brunneus -> incultorum
diminutives -> diminutivus
fuseo-fibrillosus -> brunneofibrillosus
praeclaresquamosus -> deardorffensis
silvicola -> sylvicola

The benesii, californicus, diminutivus, and sylvicola changes correct spelling.
The other four changes update names historically misapplied to the California
material; they are not general claims of taxonomic synonymy. In particular,
arvenis is a misspelling of arvensis and fuseo-fibrillosus is a
misspelling/variant of fuscofibrillosus. The original three measurements for
each renamed row match the respective current California description.

The book table itself contains the two erroneous cap-width bounds and cites
the Fungi of California Species Index as its source. Its correct reference is
Table 3.3, p. 81 (not Table 3.2 as in earlier package documentation).

Numeric corrections (cap width, cm):
- bernardii: [7, 6] in mushroom.int.mm and [6, 7] in mushroom.int
  are both replaced by [7, 16]. The old symbolic interval had the erroneous
  endpoints ordered, so checking lower <= upper alone would miss the error.
- subrutilescens: [6, 12] becomes [6, 14] in both representations.
All other measurements and all edibility codes are unchanged.

Compatibility:
The package retains the original row positions, row names, concept identifiers,
public object names, column names, and classes. Updated species names are matched
back to these row positions rather than adopting the attachment's sorted order.
The 8-column min/max table and 5-column symbolic table share the same endpoints.
The separate four-specimen Amanita dataset mushroom_fuzzy.mix is unaffected.

Rebuild from the dataSDA package root:
Rscript --vanilla data-raw/mushroom.int.R
